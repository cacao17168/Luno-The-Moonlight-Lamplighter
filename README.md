# Main
This is the source code of my game "Luno: The Moonlight Lamplighter"
## Installation
### Dependencies
Using your package manager install:

| Distribution | Package Name | Installation command |
| --- | --- | --- |
| Debian/Ubuntu | `libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev` | `sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev` |
| Arch linux | `sdl2 sdl2_image sdl2_ttf` | `sudo pacman -S sdl2 sdl2_image sdl2_ttf` |
| Fedora | `SDL2-devel SDL2_image-devel SDL2_ttf-devel` | `sudo dnf install SDL2-devel SDL2_image-devel SDL2_ttf-devel` |

### Copy repository

```bash
git clone https://github.com/cacao17168/Luno-The-Moonlight-Lamplighter.git
```
